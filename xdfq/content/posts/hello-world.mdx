## Welcome to my blog!

这是我的第一篇博客。这篇文章是用 **MDX** 写的——它既支持标准 Markdown 语法，也可以在文章里直接嵌入 React 组件。

## 代码示例

写博客当然少不了贴代码：

```ts
// lib/posts.ts — 一个简单的函数
export function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```

## 一些特性

- 🚀 **Next.js** 驱动，构建时预生成页面，访问速度飞快
- 🎨 **Tailwind CSS** 排版，支持暗色模式
- ✨ **anime.js** 驱动页面动画
- 📝 **MDX** 写文章，Markdown + React 组件随心组合
