## React Hooks

Hook 是 React 16.8 新增的特性，让你在函数组件中使用 state 和其他 React 特性。

```tsx
import { useState, useEffect } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `点击了 ${count} 次`;
  }, [count]);

  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```
